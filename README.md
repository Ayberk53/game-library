# 🎮 Game Library — Oyun Kütüphanesi ve Koleksiyon Platformu

**Game Library**, oyuncuların farklı türlerdeki yapımları keşfedebildiği, oyun detaylarını ve incelemelerini görüntüleyebildiği ve kendi kişisel oyun listelerini (Wishlist / Kütüphane) oluşturabildiği etkileşimli bir web platformudur.

## 🚀 Öne Çıkan Özellikler
* **Oyun Kataloğu ve Filtreleme:** Oyunları türlerine ve popülerliklerine göre listeleme ve arama.
* **Kişisel Kütüphane / İstek Listesi:** Beğenilen oyunları tek tıkla kişisel listeye ekleme, çıkarma ve listeyi yönetme.
* **Detaylı Oyun Kartları:** Kapak görselleri, tür etiketleri ve özet açıklamalarla sade kart tasarımı.
* **Responsive Tasarım:** Masaüstü ve mobil ekran boyutlarına uyumlu esnek ızgara (Grid) yapısı.

## 🛠️ Kullanılan Teknolojiler
* **Frontend:** React.js / JavaScript (ES6+)
* **Stil:** HTML5 & CSS3
* **Durum Yönetimi:** React State & LocalStorage
